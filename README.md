# «Наші меблі» — застосунок для телефону

Це сторінка-обгортка: ваша іконка, назва й повноекранний режим, а всередині — та сама CRM з Google Apps Script.
Оновлення CRM (нові версії) підхоплюються самі — цю сторінку міняти не треба.

## 1. Вставте посилання на CRM
1. Apps Script → **Ввести в дію** → **Керувати розгортаннями** → скопіюйте **URL вебзастосунку** (закінчується на `/exec`).
2. Відкрийте `index.html` у будь-якому текстовому редакторі й вставте посилання в рядок
   `const CRM_URL = '...';`

## 2. Розмістіть на GitHub Pages (безкоштовно)
1. Зареєструйтесь на https://github.com (якщо ще немає акаунта).
2. **New repository** → назва, напр. `nashi-mebli` → **Public** → **Create repository**.
3. **uploading an existing file** → перетягніть **усі файли й папку `icons`** з архіву → **Commit changes**.
4. **Settings** → **Pages** → Source: **Deploy from a branch** → Branch: **main**, папка **/ (root)** → **Save**.
5. За 1–2 хв з'явиться адреса: `https://ВАШ-ЛОГІН.github.io/nashi-mebli/`

## 3. Встановіть на телефон
- **iPhone (Safari):** відкрийте адресу → «Поділитися» → **На екран «Додому»**.
- **Android (Chrome):** відкрийте адресу → **Встановити застосунок** (або ⋮ → «Додати на головний екран»).

Цю ж адресу дайте партнерам — кожен входить під своїм логіном.
